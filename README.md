# Temperature Trends in Four Economies

This project analyzes temperature changes across four major economies using real‑world climate data and data science techniques. The goal is to uncover patterns, trends, and comparisons between countries, and to inform insights on climate variability and its broader implications.

## Features & Highlights

- Data cleaning, normalization, and preprocessing  
- Exploratory Data Analysis (EDA) across multiple regions  
- Comparative visualizations (line charts, trend comparisons)  
- Reproducible workflow using Python and Jupyter Notebook  

## Technologies Used

- Python (pandas, numpy, matplotlib, seaborn, etc.)  
- Jupyter Notebook for integrated analysis and narrative  
- (Optional) Exported plots or interactive visuals

## How to Run / Use

1. Clone the repository:  
   `git clone https://github.com/andreeafazacas84-eng/temperature-4-economies.git`

2. Install dependencies:  
   `pip install -r requirements.txt`

3. Open and run the notebook:  
   Use Jupyter Notebook / JupyterLab to run step-by-step analysis.

## Results & Insights

- Identified comparative temperature trends across economies  
- Highlighted periods of divergence or convergence in climate patterns  
- Provided visual evidence to support hypotheses on regional climate behavior
